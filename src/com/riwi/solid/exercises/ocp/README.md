# Prácticas OCP

Estos son los puntos de partida de las cinco prácticas de OCP. Cada carpeta contiene una clase central con condicionales deliberados; no es necesario modificar las otras prácticas para resolver una.

| Carpeta | Escenario |
| --- | --- |
| `ex01/NotificationService.java` | Notificaciones |
| `ex02/PaymentService.java` | Métodos de pago |
| `ex03/FileExporter.java` | Exportación de archivos |
| `ex04/ShippingCalculator.java` | Cálculo de envíos |
| `ex05/AttackService.java` | Ataques de videojuego |

Consulta la guía de [OCP](../../../../../../docs/06-ocp.md) y el enunciado de los [ejercicios](../../../../../../docs/07-ejercicios-ocp.md) antes de refactorizar. El cambio debe añadir una variante sin reabrir el coordinador que ya existe.

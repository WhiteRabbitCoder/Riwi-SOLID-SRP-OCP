# Prácticas LSP

Cada carpeta contiene una jerarquía que compila, pero cuya sustitución rompe una expectativa del cliente. No soluciones el problema ocultando la excepción ni preguntando por el tipo concreto; revisa el contrato que el cliente realmente necesita.

| Carpeta | Escenario | Cliente |
| --- | --- | --- |
| `ex01` | Aves y vuelo | `BirdDemo` |
| `ex02` | Rectángulos y cuadrados | `AreaClient` |
| `ex03` | Cuentas bancarias | `AccountDemo` |
| `ex04` | Pagos y reembolsos | escríbelo tú |
| `ex05` | Archivos de solo lectura | escríbelo tú |

Consulta la guía de [LSP](../../../../../../docs/09-lsp.md) y el enunciado de los [ejercicios](../../../../../../docs/10-ejercicios-lsp.md) para el orden de trabajo y los criterios de cierre.

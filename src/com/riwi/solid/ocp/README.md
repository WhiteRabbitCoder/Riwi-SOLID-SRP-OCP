# Prácticas OCP

Estos son los puntos de partida de las cinco prácticas de OCP. Cada carpeta contiene una clase central con condicionales deliberados; no es necesario modificar las otras prácticas para resolver una.

| Carpeta | Escenario |
| --- | --- |
| `NotificationService.java` | Notificaciones |
| `PaymentService.java` | Métodos de pago |
| `FileExporter.java` | Exportación de archivos |
| `ShippingCalculator.java` | Cálculo de envíos |
| `AttackService.java` | Ataques de videojuego |

Consulta la guía de [OCP](../../../../../docs/ocp.md) antes de refactorizar. El cambio debe añadir una variante sin reabrir el coordinador que ya existe.

# Prácticas LSP

Cada carpeta contiene una jerarquía que compila, pero cuya sustitución rompe una expectativa del cliente. No soluciones el problema ocultando la excepción ni preguntando por el tipo concreto; revisa el contrato que el cliente realmente necesita.

| Carpeta | Escenario |
| --- | --- |
| `ex01` | Aves y vuelo |
| `ex02` | Rectángulos y cuadrados |
| `ex03` | Cuentas bancarias |
| `ex04` | Pagos y reembolsos |
| `ex05` | Archivos de solo lectura |

Consulta la guía de [LSP](../../../../../../../../docs/lsp/README.md) para el orden de trabajo y los criterios de cierre.

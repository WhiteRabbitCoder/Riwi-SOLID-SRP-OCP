# Prácticas OCP

Estos son los puntos de partida de las cinco prácticas de OCP. Cada carpeta contiene una clase central con condicionales deliberados; no es necesario modificar las otras prácticas para resolver una.

| Carpeta | Escenario |
| --- | --- |
| `ex01` | Notificaciones |
| `ex02` | Métodos de pago |
| `ex03` | Exportación de archivos |
| `ex04` | Cálculo de envíos |
| `ex05` | Ataques de videojuego |

Consulta la guía de [OCP](../../../../../../../../docs/ocp/README.md) antes de refactorizar. El cambio debe añadir una variante sin reabrir el coordinador que ya existe.
